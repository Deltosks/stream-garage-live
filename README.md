# Stream Garage · публичное табло

Только публичные игры, баллы, шансы, результаты и журнал эфиров deltosks. Основной проект и серверный код остаются в отдельном закрытом репозитории.

Сайт не требует входа. Браузер зрителя загружает HTML, CSS, JS и снимок данных только с GitHub Pages. Twitch открывается по желанию зрителя для участия. В браузере нет обращений к chatgpt.site.

GitHub Actions получает анонимную публичную проекцию с действующего сервера, проверяет её и публикует только разрешённые поля. Никакие ключи, токены Twitch, полные выгрузки базы или личные погашения не копируются. Для синхронизации секреты не нужны.

Расписание: раз в 5 минут, со сдвигом от начала часа. GitHub может задерживать запуск; сайт показывает время снимка, предупреждает об устаревании и сохраняет последние данные при ошибках. Мгновенных обновлений эта версия не обещает. После 60 дней без активности GitHub может остановить расписание: для восстановления запустите workflow вручную или внесите изменение в репозиторий.

Проверка: `npm test`. Снимок: `npm run sync`. Предпросмотр: `npm run preview`.
